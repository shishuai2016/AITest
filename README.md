# AITest

dsh-superagent 的测试仓库：在对话里 @shishuai-agentbot 提需求，机器人自动实现并提交 PR。

## 怎么提需求

**在任意一处 @shishuai-agentbot，后面直接写需求，发送即可。**

| 入口 | 怎么操作 |
| --- | --- |
| GitHub Issue | 新建 Issue，正文写 `@shishuai-agentbot 需求` |
| GitHub 评论 | 在 Issue 或 PR 下评论 `@shishuai-agentbot 需求` |
| 飞书 | 在群里 @shishuai-agentbot，或直接私聊 |

一句话示例，复制改改就能用：

> @shishuai-agentbot 把 README 的“怎么提需求”改成三种入口的表格，每种入口写清操作步骤。

发完等它在原对话回复即可：先确认需求，再自动开分支实现，完成后把 PR 链接发回原对话。

## 需求怎么写

- **改哪里**：文件、页面或功能，能指出位置最好。
- **改成什么样**：现在是什么样、期望变成什么样。
- **怎么算完成**：验收标准（可选，但很有用）。
- 一次提一件事，范围越小越容易一次做对。
- 需求不明确也没关系，需要你拍板时它会来问。

需求有变化，直接在原对话补充，不用重新提。

## 提完之后

1. **确认**：机器人先回一句，说明接到的需求。
2. **开发**：在自己的分支上改代码、补测试并自检。
3. **交付**：完成后在原对话回复 PR 链接；需要你决定或做不了时，会说明原因。

## 注意

- 只有已授权的账号和群聊能向机器人提需求。
- 在 GitHub 上追加需求请发**新评论**；编辑 Issue 正文新增的 @ 不会被收到。
- PR 是待评审的改动，需要人来评审和合并，机器人不会自己合并。
- 这是测试仓库，欢迎直接提需求验证完整流程。
